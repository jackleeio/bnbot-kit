# BNBot Skill

AI Growth Agent for social platforms. Helps agents find trends, create content, and automate growth.

## Usage

```bash
# In Claude Code
/bnbot help
/bnbot "write a tweet about AI agents"
/bnbot "scrape trending topics from Reddit and Twitter"
```

## Setup

```bash
npx @bnbot/cli setup
```

This installs the skill into your Claude Code environment and configures the CLI tools.

## What It Does

- Find trends across 30+ platforms
- Create tweets, threads, and articles
- Repurpose content from links and videos
- Draft, schedule, and automate publishing workflows
