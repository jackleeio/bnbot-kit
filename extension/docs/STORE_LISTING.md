## Detailed Description - English

```
BNBot in Chrome

BNBot is the browser extension for the BNBot desktop app.

Use the desktop app to chat with your AI agent, then let BNBot work directly in the browser to discover trends, read social context, create content, and run approved workflows across social platforms.

WHAT IT DOES

• Discover trends across X, YouTube, TikTok, Reddit, GitHub, Product Hunt, Bilibili, Weibo, and more
• Create tweets, threads, replies, quotes, articles, and images in your voice
• Repurpose videos, articles, and posts into social-ready content
• Summarize bookmarks, threads, timelines, and web pages
• Track KOLs, analyze posts, and spot useful signals
• Run approved browser actions for publishing, replies, scheduling, and daily workflows

DESKTOP APP + BROWSER

BNBot Desktop is where you talk to your AI agent.
This extension is the browser layer that lets the agent see pages, use your logged-in sessions, and take actions you approve.

YOU'RE IN CONTROL

BNBot is designed for agent-assisted workflows. Review generated content, approve sensitive actions, and keep browser automation tied to the tasks you start from the desktop app.

GETTING STARTED

1. Install the BNBot desktop app
2. Install this extension
3. Sign in to BNBot
4. Open the desktop app and describe your task
5. Approve browser actions when prompted
```

## Privacy Notes

- Works with the BNBot desktop app
- Uses BNBot account authentication
- Uses your browser session only for the workflows you start
- Does not use your posts for AI training
- Sends API traffic over encrypted connections
- Users can delete their account and data
